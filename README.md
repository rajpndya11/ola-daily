# Ola Daily · interactive prototype
React + Vite. State persists in the browser (localStorage).

Run locally (Node 18+): `npm install && npm run dev`
Build: `npm run build` (output in `dist/`)

Launch: drag the prebuilt `dist/` folder onto https://app.netlify.com/drop, or import this folder into Vercel / Netlify (build `npm run build`, output `dist`).
